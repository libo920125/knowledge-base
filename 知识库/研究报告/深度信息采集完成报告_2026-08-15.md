### 3.3 Agent Skill 教程核心

**定义**：可插拔的专业能力模块

**本质**：
- 大模型可随时翻阅的"说明书"
- 沉淀了自然语言描述 SOP 的 Markdown 文件
- 将"怎么做"的知识，从 Prompt 中剥离出来

**渐进式加载机制**：
- Layer 1：Agent 启动时，加载元数据（约 100 tokens）
- Layer 2：Skill 被激活时，加载 SKILL.md 正文
- Layer 3：需要资源时，加载 scripts/references/assets

**标准结构**：
```
my-skill/
├── SKILL.md              # 必需：技能元数据和流程说明
├── scripts/              # 可选：可执行脚本
├── references/           # 可选：参考文档
└── assets/               # 可选：模板、配置文件
```

**5 分钟创建流程**：
1. 创建目录：`mkdir -p ~/.openclaw/workspace/skills/hello-world`
2. 编写 SKILL.md（YAML frontmatter + Markdown 指令）
3. 重启 Agent
4. 测试 Skill 激活

### 3.4 查理·芒格思维模型核心

**核心理念**：
> "手里拿着锤子的人，看什么都像钉子。"

**解决方案**：掌握多学科的核心思维模型（约 100 种）

**最重要的 10 个模型**：
1. **机会成本**：为了得到某样东西，必须放弃其他东西的最大价值
2. **激励机制**：利益捆绑是最佳驱动力（"自己打包自己的降落伞"）
3. **复利原理**：人生就像滚雪球，找足够湿的雪和足够长的坡
4. **反向思考**：先想"如何失败"，再避免
5. **第一性原理**：回到事物最基本的事实，从头推导
6. **决策树**：用树状图可视化决策过程
7. **帕累托法则（80/20）**：80% 的结果来自 20% 的原因
8. **确认偏误**：只看支持自己观点的证据
9. **损失规避**：损失的痛苦是收益快乐的 2 倍
10. **熵增定律**：封闭系统自发混乱，需持续输入能量

**应用方法**：
- 建立思维模型库（Obsidian 笔记）
- 遇到问题时，问自己"哪个模型适用？"
- 至少用 3 个模型交叉验证（"交叉火力原则"）
