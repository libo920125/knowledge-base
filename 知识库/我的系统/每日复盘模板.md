# 每日复盘 · 就 5 问

> 每晚睡前 15 分钟。**核心纪律：没有「明天的具体动作」= 没复盘完。**
> 来源：结合学习法工具箱「复盘法」+ 8.15 碎片「今天时间有没有花在主线上」自定。

## 📋 今日复盘 - YYYY-MM-DD

### 1. 今天时间花在主线上没有？
> 主线 = 口播 / 程序化成长。这条是总纲。
- 今天为口播/主线真正做的一件事：
- 如果整天没做，明天必须补的：

### 2. 今天完成了哪件事？（只写事实，不写感觉）
- [ ] 拍 / 剪 / 发了一条口播
- [ ] 读了 / 学了什么
- [ ] 处理了店 / 财务的事
- （其他：）

### 3. 今天卡在哪、为什么？（识别报错）
- 卡住的那件事：
- 判断：这是「累」（该休息）还是「懒 / 没启动」（动作太大）？
- 下一步只调这一处：

### 4. 今天有没有一个「能讲给人听」的点？
> 标准只有一条：能不能用大白话讲给一个朋友听？
> 讲得出 = 这算你学到的；讲不出 = 它只是「看过」，不算你的，别记，也别慌。
- 用大白话写那一句（哪怕很碎）：
- 它能不能变成一条口播素材？（能就直接记一句标题）

### 🧠 主动学习检查（每天必答）
> 今天有没有"主动"学习？（自己去找/去用/去讲一个东西，不是别人喂的、不是看完就丢）
- 今天我自己主动做的一个学习动作：____
- 它是"被动接收"还是"我主动去找/用/验证"了？

### 5. 今天哪件事没做好？明天改它
> 不用凭空想新动作——只要挑出今天「没做好」的那一件事，明天专改它，那就是你明天的新动作。一次只改一处。
- **今天哪件事我没做好**：____（如：开头钩子不够狠 / 中间太拖 / 学到的没用出去）
- **明天我专改这一处**：____（如：把开头改得更狠）

## 💡 用的时候记住
- **死记一条**：结尾永远以「明天的具体动作」收尾。写不出动作 = 没复盘完。
- 每一问答一行，别写长篇。写太多了你就不想天天做了。
- 用多了它会变成你的「报错日志」——攒出来就是你复盘不泛的最硬素材。
