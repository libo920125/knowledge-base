# 学习法工具箱 · 给小李的学习手册

> 用途：你自己扩容知识库用。每一个方法都能"拆成程序"跑起来，也都能量身改成一期口播。
> 原则：不囤资料，每个方法你挑一个"本周就开始跑的最小版"去执行，跑通再学下一个。
> 更新：2026-08-14

---

## 0. 使用建议（先看这个）

你现在的处境是"想学的东西很多，但精力有限"。所以别贪多，遵守：
1. **一次只启动一个方法**，把它当程序跑3天，能跑通再加下一个。
2. **学任何一个新东西，先用费曼学习法**（见 [[费曼学习法]]）：学→讲给外行→卡住回去补→讲剩最简。
3. **学到的方法都要能落地成"你今天就能做的动作"**，否则不进库。

下面每个方法都按这个格式给：它是什么 → 怎么当成程序跑 → 你改编口播的切入点。

---

## 一、微习惯（把"坚持"的门槛降到几乎为零）

**它是什么**：出自斯蒂芬·盖斯《微习惯》。核心不是"每天进步一点点"，而是**把动作小到"不可能失败"**——比如"每天1个俯卧撑"。因为大脑不怕小任务，一旦启动，惯性会让你多做。
> 关键：目标要小到"不做反而是异类"的程度，你才会上瘾地长期跑。

**怎么当程序跑：**
```
启动开关（触发条件）：每天刷完牙/进门后，固定一个时间点
最小动作（小到无法拒绝）：1个俯卧撑 / 1页书 / 写3行复盘
跑3天后：观察"启动成功率"——目标就是100%启动
报错debug：如果连着2天没启动，说明动作还是太大，再砍一半
```

**为什么要学**：这是你"启动开关/降低意志力需求"的理论背书，直接证明"程序化比意志力靠谱"。而且它本身就能跑通——你减重40斤本质就是在用"微启动"。

**改编口播**：《不用早起365天，我靠一个"微启动"就装上了自律》／《减肥最怕的其实是"开始"，微习惯帮你把开始变得无痛》。

---

## 二、复盘法（治你"复盘比较泛"的短板）

**它是什么**：复盘不是"今天干了啥、感觉如何"，而是**对照结果找卡点**。柳传志版四步：回顾目标 → 评估结果 → 分析原因 → 总结规律。你的短板是"比较泛"，所以要刻意把它**结构化、数据化、落到下一动作**。

**怎么当程序跑（五天柱复盘法，专治泛）：**
```
① 结果：今天/这周，我实际做了什么？（只写事实，不写感觉）
② 指标：对应我设的目标，偏离了没？（超出/达成/未达）
③ 报错：哪里卡住了？卡的原因是"累"还是"懒"？（区分:累=真需要休息,懒=动作太大或没启动）
④ 调试：这一个卡点，我下一轮只调一个地方（单点调整）
⑤ 下一步：明天/下周，具体的1-3个动作（必须是"可执行动词"，不是"更自律"）

死记一条：复盘结尾永远以"明天的具体动作"收尾，没有具体动作=没复盘完。
```

**为什么要学**：你自省口播"复盘泛"，这个方法直接给你一个现成的工具——既是你的学习，也是你口播的独家素材（"我用5栏复盘法，替代了'今天还行'"）。

**改编口播**：《我复盘了300天，总结出一个不泛的复盘法》／《普通人逆袭最快是狠狠复盘——但别复盘情绪，复盘这5栏》。

## 三、目标拆解（把"想"变成"程序"）

**它是什么**：多数人的目标是一句感觉——"我要瘦"。好的目标要**拆成结果→指标→里程碑**，并给每个里程碑定一个可验证的完成条件（OKR思维 + 加减法两层：先做减法定方向，再做加法补动作）。

**怎么当程序跑：**
```
结果（模糊愿望）→ "我要健康"（废，无法执行）
指标（可量化）  → "体重从80kg到60kg"
里程碑（阶段点）→ "第1个月-5kg / 第2个月-5kg / 第3个月-5kg / 第4个月-5kg"
动作（每阶段）  → 每天2顿轻食+3次力量训练+记录体重（频率/内容都要写死）
验证节点        → 每周称一次重，偏离≥1kg就触发debug，找这一个卡点
```

**为什么要学**：这正是你"设定目标程序(结果→指标→里程碑)"的理论化，学会它你就能把"程序化减重"讲得更专业、更能卖课。

**改编口播**：《你把"我想瘦20斤"当目标，当然会失败》／《目标别"想"，要"拆"成程序：三步拆法》／《"减40斤"和"今天20个俯卧撑"，哪个才是好目标？》。

已在 [[费曼学习法]] 详讲。核心提醒：**练口播=练费曼**。你每期把一件事讲到外行能听懂，就是一次费曼输出。这是你和别的成长博主之间，最被低估的优势。

## 五、番茄工作法 / 极简任务管理（时间管理，给"执行段"兜底）

**它是什么**：番茄工作法=工作25分钟休息5分钟。极简版：**不用复杂工具，一天只定1-3个"今天的最大石头"**，先啃最大的，别的排后。

**怎么当程序跑：**
```
每天早上(启动)：写今天最想完成的1件事(唯一)
执行段：用番茄钟专注25分钟,手机放隔壁屋
休息段：5分钟,起身,不看手机
结束(复盘):今天这件事完成了吗?卡在哪?(进上面的复盘法)
```

**为什么要学**：你"低能耗高产出"，但碎片时间多（盘库间隙/等接盘人）。这个方法帮你把碎片切成分段专注，效率即时可见。

**改编口播**：《一天只干一件最重要的事，我的效率反而翻倍》／《碎片时间的大招：不是挤时间，是切专注段》。

## 六、本阶段"开始跑"的建议排序（别全学）

按你现在"碎片时间拍口播攒账号"的主线，给你排个优先级：

1. **先跑【微习惯】**（最低门槛，第1天就能启动，3天见效）→ 它给你"能长期跑"的正反馈。
2. **同时用【高效复盘】**（5栏法）→ 每次拍完口播用5栏复盘，治你"泛"的毛病，直接提升内容质量。
3. **别急着学花时间的方法**（番茄/极简任务管理等）→ 等店转出去、有整块时间了再补。
4. **学任何新东西，先过【费曼】这关**：学一遍→能讲给外行听才算会。

> 一句话：别囤方法，先跑通微习惯+复盘这两个，它们也直接是你的口播弹药。

## 七、进阶补充（子代理抓取整理 · 2026-08-14）

> 下面是上一批没覆盖的、网上公认可执行的方法，都已步骤化。还是那句话：一次只跑一个，能跑通再加。

### 十、刻意练习（比"只要努力"强很多的练法）
核心不是"重复次数多"，而是**每次都在能力边缘+有即时反馈**。
```
① 拆技能：把要练的东西拆成小块（如拍口播拆成:开头钩子/语速/脚本结构）
② 定标准：每题都有"合格线"（如开头5秒必含一个数字或痛点）
③ 找反馈：每拍完一条立刻看数据/找人评，不隔夜
④ 针对性修：只改最差的那一块，一次一个参数
> 你拍口播天然就是"刻意练习"——每次看完播率就是在拿即时反馈练钩子。
```

### 十一、习惯四步回路（提示—渴求—反应—奖赏）
> 出自《掌控习惯》。所有习惯都绕不开这4环，改习惯盯这4环。
```
① 提示:让它显而易见（把瑜伽垫铺开放在客厅）
② 渴求:让它更有吸引力（把健身和爱看的剧绑定）
③ 反应:让它简单易行（降到微习惯级别）
④ 奖赏:让它令人愉悦（跑完立刻给个"已完成"勾/小奖励）
> 你的"程序=提示/行动/奖赏"，本质就是这个回路。想改哪个习惯，就改对应那环。
```

### 十二、WOOP目标法（给目标装"障碍预案"）
> W-Wish愿望 / O-Outcome结果 / O-Obstacle障碍 / P-Plan计划(if-then)
```
① Wish:我的愿望(如减10斤)
② Outcome:最好的结果(穿上以前的裤子)
③ Obstacle:最大的障碍(晚上想吃烧烤)
④ Plan:if 想吃烧烤,then 先喝一大杯水+刷牙
> 关键在④:提前写好"如果X就做Y"的预案,比临时硬扛强10倍。这正是你"报错预处理"。
```

### 十三、精力管理（把它当"电池"，别只管理时间）
> 自律高手不是靠意志力硬耗，是靠"早上的满电量干难事"。
```
① 识别低谷:精力最差时段(多是你午后/晚8点)别安排要动脑的事
② 保护巅峰:把最难最重要的事排在精力最好的1-2小时
③ 主动恢复:不是累到不行才休息,是工作一段主动歇5-10分钟
> 你"低能耗高产出"就是这套——学会识别你的巅峰段,把拍口播/直播放到那。
```

### 十四、时间块管理（给时间"分片调度"）
```
① 画块:把一天分成几个块(创作块/杂事块/休息块)
② 塞事:每件事分到对应块,不跨块乱窜
③ 留白:一定留一个"缓冲块"给突发(盘库/等接盘人)
> 你现在碎片时间多,别硬凑"整块",按"短专注块"来分。
```

### 十五、PDCA复盘闭环（比"写日记"更结构）
```
P-Plan计划 → D-Do执行 → C-Check检查 → A-Act修正
> 这就是你"设定→执行→反馈→迭代"的另一种叫法。适合周复盘:过去一周计划/做到了没/差在哪/下周改哪个。
```

### 十六、轻量复盘：5Why + KPT（快速版）
```
5Why:对卡住的问题连问5个"为什么",挖到根因(别停在表层)
KPT法:Keep保留/Problem问题/Try尝试(每项只写一句,不写感悟)
> 治你"复盘泛":别写"今天还行",用KPT三栏逼自己写具体。
```

### 十七、主动回忆+间隔重复（治"学完就忘"）
```
主动回忆:学完立刻合上书,凭记忆默写/讲一遍(费曼第2步就是它)
间隔重复:隔1天/3天/7天/14天各复习一次,比一次背很多遍有效
> 配合费曼:学完当晚"讲一遍'',隔天"再讲一遍'',忘掉的地方回去补。
```

### 十八、系统化自律（把自律"设计"进环境）
> 结论:自律不是靠坚持,是靠"环境让错误变难、让正确变易"。
```
① 物理:零食盒里只放健康食物/手机充电器放客厅(想刷得起身)
② 流程:把每天要做的固定成不假思索的流程(起床=刷牙→称重→喝咖啡)
③ 触发:给要养成的习惯配一个固定"开关"(一进健身房就先做6个深蹲)
> 这就是你"环境设计/降低意志力需求"的理论底子,把它讲成口播=金句来源。
```

### 十九、一天系统串流（综合落地版）
```
早上(启动):确定今天唯一的1件事 + 称重记录
执行(难点区):精力巅峰段,先跑最难/最重要的事
白天(微习惯):见缝插针跑1-2个微动作(记录/拉伸)
晚上(复盘):P-D-C-A 或 5栏复盘 + 定明天1件事
> 一天闭环 = 你"把自己当程序"的最小运行单位,也正好是口播连载素材。
