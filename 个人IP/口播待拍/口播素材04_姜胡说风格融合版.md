# 口播文案 · 姜胡说风格融合版

> 融合方式：姜胡说的"我"视角 + 你的"微启动程序"内容
> 目标：2秒跳出率 < 35%

---

## 📹 版本A：故事驱动型（推荐）

```
我减了40斤，不是靠坚持。

我发现了件事——我每次放弃，都不是在中途，而是在开始。

你算着"要跑5公里"，还没动就被吓回去了。

后来我把"开始"拆到小到不可能失败的那一下。

我叫它——微启动程序。

减肥？不是"今天跑5公里"——是"5秒把鞋穿上"。

读书？不是"读一小时"——是"5秒翻开第一页"。

这一下，谁都做得到。

把开始拆到够小，你就赢了今天。

你今晚最想做、却一直没动的是哪件？
评论区打出来，我帮你拆。
```

**秒级拆解**：

| 秒 | 内容 | 钩子/作用 |
|----|------|-----------|
| 0-3 | "我减了40斤，不是靠坚持。" | ✅ 数字反差 + "我"的故事 |
| 3-8 | "我发现了件事——我每次放弃，都不是在中途，而是在开始。" | ✅ 现象抛出，引发好奇 |
| 8-13 | "你算着'要跑5公里'，还没动就被吓回去了。" | ✅ 观众痛点，有画面感 |
| 13-18 | "后来我把'开始'拆到小到不可能失败的那一下。我叫它——微启动程序。" | ✅ 方法来了，有名字 |
| 18-25 | "减肥？不是'今天跑5公里'——是'5秒把鞋穿上'。读书？不是'读一小时'——是'5秒翻开第一页'。" | ✅ 具体例子，可操作 |
| 25-28 | "这一下，谁都做得到。" | ✅ 降低门槛，给信心 |
| 28-32 | "把开始拆到够小，你就赢了今天。" | ✅ 金句收尾 |
| 32-36 | "你今晚最想做、却一直没动的是哪件？评论区打出来，我帮你拆。" | ✅ 互动钩子 |

**预计时长**：35-40秒

## 📹 版本B：观点驱动型

```
你有没有发现——你每次放弃，都不是在中途，而是在开始？

我以前也是——算着"要跑5公里"，还没动就被吓回去了。

后来我发现：不是我没毅力，是我把"开始"搞太大了。

我减了40斤，靠的不是坚持。

是把开始拆到小到不可能失败的那一下——

5秒把鞋穿上，就这一下。

做完这一下，你才看得到后面。

用结果换钱，不是用时间。

把开始拆到够小，你就赢了今天。

你今晚最想做、却一直没动的是哪件？
打出来，我帮你拆。
```

**秒级拆解**：

| 秒 | 内容 | 钩子/作用 |
|----|------|-----------|
| 0-3 | "你有没有发现——你每次放弃，都不是在中途，而是在开始？" | ✅ 反问 + 反常识观点 |
| 3-8 | "我以前也是——算着'要跑5公里'，还没动就被吓回去了。" | ✅ 我的经历，共鸣 |
| 8-13 | "后来我发现：不是我没毅力，是我把'开始'搞太大了。" | ✅ 观点来了 |
| 13-18 | "我减了40斤，靠的不是坚持。是把开始拆到小到不可能失败的那一下——" | ✅ 数字证据 + 方法 |
| 18-23 | "5秒把鞋穿上，就这一下。做完这一下，你才看得到后面。" | ✅ 具体操作 |
| 23-28 | "用结果换钱，不是用时间。把开始拆到够小，你就赢了今天。" | ✅ 姜胡说金句 + 你的金句 |
| 28-32 | "你今晚最想做、却一直没动的是哪件？打出来，我帮你拆。" | ✅ 互动钩子 |

**预计时长**：30-35秒

## ✅ 我的建议

### 先拍版本A（故事驱动型）

**原因**：
1. 姜胡说风格最明显（"我减了40斤"开头）
2. 有故事、有方法、有互动
3. 容易模仿他的"我"视角

### 拍完发出去，看数据

| 看什么 | 目标 |
|--------|------|
| 2秒跳出率 | < 35% |
| 5秒完播率 | > 20% |

### 如果数据不好，试版本B

- 版本B开场更直接（反问）
- 如果版本A跳出率高，说明开场不够抓人

## 💡 拍摄提示

### 版本A的开场

```
我减了40斤，不是靠坚持。
```

**语气**：
- 不要激动，要平静
- 就像在跟朋友聊天
- "我减了40斤"要重音，"不是靠坚持"要轻

### 版本A的中段

```
我发现了件事——我每次放弃，都不是在中途，而是在开始。
```

**语气**：
- "我发现了件事" → 要有停顿，像在思考
- "在中途"和"在开始"要有对比
- 不要快，要让观众听清

### 版本A的收尾

```
把开始拆到够小，你就赢了今天。
```

**语气**：
- 这句要慢，要稳
- "赢了今天"要有力量感
- 这是金句，要让人记住
