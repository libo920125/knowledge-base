## 📹 完整文案

```
我把自己当程序，闹钟一响，自动执行。

以前我靠意志力——闹钟响了，关掉，再睡10分钟。

后来我发现一件事：

意志力是电池，程序是插电的。

电池会没电，程序不会。

所以我给自己装了个触发开关——

闹钟一响，不做选择，身体先动。

脚落地，站起来，人就醒了。

不是靠毅力，是靠程序。

闹钟不是为了提醒你，是为了给你一个触发开关。

你给自己装过触发开关吗？
评论区说一个，我看看你装的是什么程序。
```

## 🎬 拍摄提示

### 开场（0-3秒）

```
我把自己当程序，闹钟一响，自动执行。
```

**语气**：
- 平静、坚定
- "我把自己当程序"要慢一点，像在陈述一个事实
- "自动执行"要干脆

### 中段金句（8-14秒）

```
意志力是电池，程序是插电的。
电池会没电，程序不会。
```

**语气**：
- 这是最重要的一句话
- "电池"和"程序"要有对比
- "程序不会"要慢，让人记住

### 收尾（25-36秒）

```
闹钟不是为了提醒你，是为了给你一个触发开关。
```

**语气**：
- 慢、稳、有力量
- "触发开关"是核心词，要重音
- 最后互动要自然，像在问朋友
