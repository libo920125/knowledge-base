# 口播素材03：《73万播放，600粉，0单——我靠这条复盘重新开始》

> 状态：待拍 ｜ 系列B（已验证能留人）｜ 2026-08-14
> 用途：立人设+真诚复盘，用你实测过最强的"反常识数字对比"钩子
> 目标人群：做过内容/也想做内容但还没变现的人、怀疑"播放量=钱"的人

---

## 口播稿（只读大意，别背稿）

**开头（黄金3秒，数字直接砸）：**
"我做过一条73万播放的视频，最后只换来600个粉丝、0单成交。
今天我把这条复盘拆给你看——不是教你怎么火，是告诉你为什么'火了'也没用。"

**中段（讲透具体原因，不泛）：**
先交代背景，一句带过，不卖惨：
我34岁，西安人在兰州开了6年店，现在店在盘库转让。去年我拿碎片时间做了20天AI漫剧，白天守店，晚上剪，出了一条73万播放的爆款。

很多人以为 73万播放 = 稳了。其实那是我最虚的一天。我复盘了三个"拆穿"：

第一拆，播放量是谁给的？
73万播放，是平台的算法给的，不是观众主动找来的。它把我的视频扔进了一个巨大的流量池，人人都可能刷到一眼——但刷到不等于喜欢，更不等于记住我这个人。所以播放量再高，它买不来"信任"。

第二拆，600粉为什么留不住？
73万播放只换来600粉，等于刷到的人里，99.9%划走了。这说明什么？说明我这条视频的"内容"是好看的（所以算法推荐），但我的"账号人设"是空的。观众记住了那条视频，没记住这个号。流量是内容给的，粉丝是"你是谁"给的——这两件事我一分清楚，就知道自己缺在哪了。

第三拆，0单为什么理所当然？
因为没有"信任"就没有成交。600个粉丝里，没几个人知道我是谁、我靠谱不靠谱、我卖的东西值不值。信任不是播放量堆出来的，是长期"兑现承诺"攒出来的。我连账号该立什么人都没想清楚，还想着卖货——这不叫没机会，叫没准备好。

**结尾（给一个能带走的东西 + 互动）：**
所以我把这条复盘总结成一句话，你能直接带走：
"播放量是借来的流量，粉丝是记住你的人，成交是相信你的人。"
想赚钱，顺序别搞反：先让人记住你，再让人相信你，最后才谈成交。

我现在不追播放量了，先做让别人记住我这个人、相信我这个人内容——口播比漫剧更适合，因为镜头前的是真我。
你要是也在做内容，卡在"有播放没成交"，评论区告诉我你现在卡在"记住、相信、成交"哪一步，我帮你看一眼。

## 核心记忆点（别背，记住这三个词）
**拆穿播放量 / 粉丝看人设 / 成交看信任**
顺序：记住 → 相信 → 成交

---

## 拍摄提示
- 开头三个数字（73万 / 600 / 0）要慢、要清楚，这是黄金3秒的钩子
- 中间三段拆解，每段先给"反常识判断"再给"原因"，节奏快一点
- 语气平静坚定，不卖惨、不说教，像蹲路边跟朋友把一件想通的事说透
- 结尾那三个词一定说出来，这是可带走的东西，会被人截图
