# 封面生成脚本 - 一键出全套封面

## 使用方法

**输入**：标题列表（最多7个）
**输出**：7张统一风格封面（暖白木纹背景+深棕大字+暖灰副标题）

### 快速使用

在终端运行：
```powershell
cd C:\Users\Administrator\Desktop\我的文档仓库\个人IP\封面图
python make_covers_from_titles.py
```

脚本会读取 `titles.txt`（每行一个标题），自动生成7张封面。
