# 口播实验库 · 索引

> 每次口播实验都记录在这里，用数据驱动迭代。
> 一个实验 = 一个变量 = 一次对比 = 一个结论。

---

## 📋 实验原则

### 1. 每次只改一处

| 原则 | 说明 |
|------|------|
| ✅ 只改一个变量 | 比如"只改开场"，其他不变 |
| ❌ 不要同时改多处 | 比如"改开场+改语速+改画面"，无法判断哪个有效 |

### 2. 用数据说话

| 核心指标 | 说明 |
|----------|------|
| **2秒跳出率** | 最核心，决定开场是否有效 |
| 5秒完播率 | 决定前3秒是否有效 |
| 平均播放时长 | 决定整体内容是否留人 |
| 完播率 | 决定结尾是否有效 |

### 3. 记录对比

每个实验必须包含：
- 对照组数据（改之前）
- 实验组数据（改之后）
- 对比结论

### 4. 建立最优解库

```
验证有效的 → 存入"最优解库" → 以后照用
验证无效的 → 存入"踩坑库" → 以后避开
待验证的   → 继续实验
```
