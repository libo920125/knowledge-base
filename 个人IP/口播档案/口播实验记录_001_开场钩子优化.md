# 口播实验记录 #001 · 开场钩子优化

> 实验目的：测试"钩子型开场"能否降低2秒跳出率
> 实验日期：2026-08-17
> 对照组：2026-08-16 视频（43%跳出率）

---

## 📊 实验设计

### 假设

> 「讲道理型开场」跳出率高 → 「钩子型开场」能降低跳出率

### 对照组数据（昨天视频）

| 指标 | 数据 |
|------|------|
| 播放量 | 30 |
| 2秒跳出率 | **43%** |
| 5秒完播率 | 11.4% |
| 平均播放时长 | 3秒 |
| 完播率 | 0% |

### 对照组开场

```
「你那些计划——减肥、读书、早起——不是死在没毅力，是死在"开始那下太大"。」

问题：
- 讲道理型，无钩子
- 信息密度高，观众反应不过来
- 教训感，观众本能抗拒
```

---

## 🧪 实验组文案（今天）

### 实验组开场

```
「你有没有发现一件事——你每次放弃，都不是在中途，而是在开始？」

优点：
- 反问+反差，有悬念
- 第1句给钩子，让观众想继续看
- 不教训，而是引导思考
```

### 完整文案

```
你有没有发现一件事——

你每次放弃，都不是在中途，而是在开始？

你算着"要跑5公里、要读一小时"，还没动，就被吓回去了。

不是你没毅力——是你把"开始"搞太大了。

我减了40斤，不是靠逼自己坚持。

是靠一件事：把开始拆到小到不可能失败的那一下。

我叫它——微启动程序。

就一个动作，5秒内能完成：

减肥？不是"今天跑5公里"——是"5秒把鞋穿上、站起来"。

读书？不是"读一小时"——是"5秒翻开第一页"。

早起？不是"明天6点起"——是"闹钟响、5秒坐起来"。

就这一下。做完了，你才看得到后面。

记住这句：意志力是电池，程序是插电的。

把开始拆到够小，你就赢了今天。

你今晚最想做、却一直没动的是哪件？评论区打出来，我帮你拆成5秒能做的那一下。
```

### 核心变化

| 维度 | 对照组 | 实验组 |
|------|--------|--------|
| **开场类型** | 讲道理型 | 钩子型（反问+反差）|
| **第1句** | 信息密度高 | 单一钩子点 |
| **教训感** | 强 | 弱 |
| **悬念** | 无 | 有（"不是在中途，而是在开始"）|
