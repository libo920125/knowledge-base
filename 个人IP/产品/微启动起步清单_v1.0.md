## 核心方法：微启动三步

### 第一步：找触发开关

**不是"我要早起"，而是"闹钟响→脚落地"。**

触发开关 = 一个具体的动作，不是抽象的目标。

**例子：**

| 抽象目标 | 触发开关 |
|---|---|
| 我要早起 | 闹钟响→脚落地 |
| 我要读书 | 回家→打开书翻到第1页 |
| 我要健身 | 换上运动鞋 |
| 我要学英语 | 打开App点第一个单词 |

---

### 第二步：拆到5秒能开始

**不是"我要跑5公里"，而是"我要穿鞋出门"。**

微启动 = 小到不可能失败的第一步。

**为什么是5秒？**

- 5秒内能完成 = 大脑来不及找借口
- 超过5秒 = 大脑会想"算了""明天再说""太累了"

**例子：**

| 目标 | 5秒启动 |
|---|---|
| 跑5公里 | 穿上跑鞋 |
| 读30分钟书 | 翻开书看第1句 |
| 做100个俯卧撑 | 做1个俯卧撑 |
| 学1小时英语 | 打开App点1个单词 |

---

### 第三步：自然延续

**不是"做完就停"，而是"做完了继续做"。**

自然延续 = 启动后不刻意坚持，让它自己跑下去。

**我的减重过程：**

1. 触发开关：晚上10点→换上运动鞋
2. 5秒启动：出门走1圈
3. 自然延续：走完1圈→走第2圈→走第3圈→...

**18个月后：200斤→160斤。**
