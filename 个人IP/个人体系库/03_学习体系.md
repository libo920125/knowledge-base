## 学习体系的本质（先说清楚）

普通人学习：学 → 忘 → 学 → 忘（无效循环）
高效学习：学 → 用 → 产出 → 存进大脑

**你现在的目标不是"学更多"，是"把学到的东西变成产出"。**

---

## 你的三大学习问题 & 解法

### 问题1：记不住
**解法：输出倒逼输入**

不要"看完再输出"，要"学了就输出"。

| 学了什么 | 马上输出 |
|---|---|
| 看了一篇爆款分析 | 写一条口播脚本 |
| 学了一个方法 | 想办法用进今天的口播里 |
| 看了一个视频 | 用自己的话讲一遍（录音或打字） |

> **原则：学到的东西24小时内必须用一次，不用就会忘。**

---

### 问题2：不知道学什么
**解法：围绕"变现"来学**

你现在在学内容创作，学的东西必须回答这个问题：

```
"这个知识，能帮我明天/下周 多赚一分钱/多涨一个粉/多出一条内容吗？"
```

如果不能，这个知识先放一边，先学能直接用的。

**你现在要学的三件事（按优先级）**：

1. **写（文案/口播）**——最直接，能变现
2. **数据解读**——知道什么内容有效、什么无效
3. **用户洞察**——知道你的用户在想什么、要什么

其他（工具技巧、方法论、理论）往后排。

---

### 问题3：不知道怎么用
**解法：最小应用法**

学到任何一个知识点，问自己：

> "我今天能把这个用在哪里？"

没有"用在哪"就重新学，直到找到为止。

## 每日学习流程（4-5小时怎么用）

### 时间块分配

| 时段 | 时长 | 做什么 | 关键动作 |
|---|---|---|---|
| 早 | 1-1.5小时 | 输入：学 | 看书/看内容/听课 |
| 中 | 1小时 | 转化：输出 | 用学到的东西写/做 |
| 晚 | 1小时 | 归档：存入知识库 | 整理今天学到的，放进Obsidian |

### 每日学习标准流程

```
① 早上定目标：今天我要学哪个具体的东西？
  → 不是"学内容创作"，是"学怎么写开头钩子"

② 学的时候记笔记：不是抄，是用自己的话写
  → 格式："我今天学到了___，可以用在___"

③ 学完马上用：今天能不能用进一条口播/一篇文章？
  → 能用 → 马上用
  → 不能用 → 问："我怎么才能用它？"

④ 晚上归档：把今天学到的一句话放进Obsidian
  → 放在"学习日志/今日心得"页面
```

## 知识库的用法（你的第二大脑）

```
每天学了什么 → 写进 Obsidian 当天笔记
                    ↓
              每周整理一次：
              → 有用的 → 放进"方法卡片库"
              → 没用的 → 删除
                    ↓
              每月回顾：
              → 这个月学的东西，有多少用进了产出？
              → 用了 → 标记"已验证"
              → 没用了 → 删除或重学
```
