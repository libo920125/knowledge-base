## 向上思维的本质（先搞清楚）

"向上"不是变得更聪明，是**学会从更高的地方看问题**。

| 低维度视角 | 高维度视角 |
|---|---|
| 这件事怎么做 | 这件事值不值得做 |
| 这个选择对不对 | 5年后这个选择还在不在 |
| 我现在缺什么 | 我要到达哪里、现在在哪 |
| 别人怎么看我 | 我真正想要的是什么 |
| 机会太多了 | 我该拒绝什么 |

## 你的三个核心工具

### 工具1：向上看的"三步问法"

遇到任何问题，先问自己这三步：

**第一步：这件事往上三层是什么？**

> 例："我要不要拍这条口播"
> → 往上三层：我做口播是为了什么？（转型/赚钱/帮内耗者）
> → 所以这条口播有没有帮到这个目标？

**第二步：5年后我怎么看这件事？**

> "今天拍这条口播"
> → 5年后看：这是我转型路上的第几步？
> → 会影响5年后的结果吗？
> → 如果不影响，现在不用纠结

**第三步：我拒绝什么？**

> 知道自己不要什么，比知道自己要什么更重要。
> 列出3件你现在在做但5年后回头看是浪费时间的事。

### 工具3："厉害的人"的思维习惯（你可以学）

你说过你帮朋友解决过生意上的小矛盾。

把这个过程拆开：

```
问题来了 → 你怎么想 → 你想到了什么 → 你给出了什么建议 → 结果是什么
```

这就是一个完整的"分析问题 → 给方案"的思维过程。

**向上思维就是：把这个过程练到看到任何问题都能跑通。**

## 你的决策过滤器

遇到事情，先问：

| 问题 | 如果YES | 如果NO |
|---|---|---|
| 这件事跟"内容创业转型"有关吗？ | 做 | 砍 |
| 5年后这件事还在我的路上吗？ | 做 | 砍 |
| 今天能变成一条口播/一个产出吗？ | 做 | 砍 |
| 做这件事我要押多少钱？ | 超过0就慎重 | 零成本就试 |

> 三个NO就砍，一个YES就做。
