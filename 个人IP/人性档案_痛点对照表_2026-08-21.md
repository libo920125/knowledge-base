## 逐类拆解（口播照着讲）

### 一、内耗 / 想太多 / 焦虑（1-16）
- **困局**：稀缺心态占用认知带宽，白天被生存（房租/工资/琐事）占满，晚上有余闲才敢想（"千条路"），但没程序接住→第二天一睁眼被管窥效应拉回原路。焦虑 = 不安全感（抗风险≈0）。
- **代表问题**：#9 晚上想想千条路，早上醒来走老路；#7 明明想改变就是迈不出第一步。
- **口播讲法**："你不是想太多，是你脑子里那点带宽，白天全被房租水电占满了。晚上才腾出来想，但没个程序接着，第二天一睁眼又被拽回原路。"
- **落句金句**：「晚上千条路，早上走原路——不是你懒，是你没给'想'装个出口。」

### 二、拖延 / 完美主义（17-22）
- **困局**：完美主义 = 怕做错浪费有限资源（稀缺下容错低）；"准备完美再行动" = 风险厌恶锁死决策；尝试被否定→自我否定闭环。
- **代表问题**：#20 完美主义因怕完成不好而拖延；#17 拖延症太严重想去改变但没用。
- **口播讲法**："你不是懒，是怕。怕做不好，怕浪费本来就少的本钱。但越等越不敢，最后连开始都省了。"
- **落句金句**：「完美主义不是高标准，是怕失败的遮羞布。」

### 三、三分钟热度 / 坚持不下去（23-39）
- **困局**：被驯化成"只要结果不要过程"；靠意志力（电池）必然没电；缺余闲→一次中断就崩；减肥类（36-39）尤其典型——没反馈回路，靠"必须坚持"硬撑。
- **代表问题**：#23 想一口气学完又不认真；#36 减肥坚持不下去。
- **口播讲法**："你不是三分钟热度，是你从一开始就要'感觉有用'才动。没反馈的日子你撑不住，因为没人告诉你'对了'。"
- **落句金句**：「三分钟热度不是你不行的证据，是你一直靠电池没插电。」

### 四、迷茫 / 没方向 / 30岁焦虑（40-59）
- **困局**：环境锁定（圈子决定想象力）；30岁发现"稳定"是陷阱（稳定幻觉破灭）；继承对失败的恐惧（认知继承）；阶层固化焦虑。创业不知从哪开始 = 信息差（机会来时最后知道）。
- **代表问题**：#44 30岁一事无成如何逆袭；#40 想创业不知道怎么开始。
- **口播讲法**："你不是没方向，是你周围没人干过你想干的事，你的想象力被圈子锁死了。我34岁欠债快失业，也是这么过来的。"
- **落句金句**：「迷茫不是你的问题，是你圈子的问题。想不清，先换个圈子。」

### 五、想提升 / 学技能不知学啥（60-70）
- **困局**：信息质量分层（穷人圈不传"行业时机"）；线性思维（以为学个技能就线性涨薪）；越焦虑越学不进（带宽被占）。
- **代表问题**：#66 想提升但不知学啥很焦虑；#60 想学技术不知学什么。
- **口播讲法**："你不是不想学，是你根本不知道该学啥——因为能赚钱的信息，到你耳朵里时已经是别人接盘的时候了。"
- **落句金句**：「不是你学不会，是你学的信息，本来就慢了别人三五年。」

### 六、读书静不下心（71-79）
- **困局**：生存焦虑占带宽，脑子转不动；读书是延迟满足，和短视频即时反馈打架；被驯化的即时满足。
- **代表问题**：#71 想看书但一直想看不进去；#75 想看书却看不进去。
- **口播讲法**："你不是坐不住，是你脑子里那根弦白天绷了一天，晚上一坐下，短视频给你一秒爽，书要十分钟才有用，你的大脑早被训成只要立刻爽了。"
- **落句金句**：「看不进书不是你定力差，是你的大脑被训成了'立刻要爽'。」

### 七、在意别人眼光 / 怕被嘲笑 / 怕失败（80-88）
- **困局**：被灌输"我们家就这样"（自我否定闭环）；怕做错 = 怕浪费有限资源 / 丢仅有的体面；恐惧与雄心拉锯。
- **代表问题**：#80 想做怕别人目光；#87 害怕失败不敢尝试。
- **口播讲法**："你不是怂，是你从小被训成'别出头'。但你想做的事，等别人都鼓掌那天，黄花菜都凉了。"
- **落句金句**：「怕别人笑，是你给自己先判了刑。」

### 八、手机依赖 / 早起困难（89-95）
- **困局**：刷手机是逃避生存焦虑的"精神避难所"；多巴胺劫持（即时满足被驯化）；早起困难 = 缺触发程序 + 晚上带宽耗尽。
- **代表问题**：#90 一看短视频就停不下来；#93 调很多闹钟还是起不来。
- **口播讲法**："你不是手机瘾，是你一天被现实揍完，晚上只想找个洞躲。短视频就是那个洞。但躲进去，第二天还是原样。"
- **落句金句**：「刷手机不是你自控差，是你白天太累了，需要个洞躲。——但洞里没有答案。」

### 九、转行 / 副业 / 自媒体（96-105）
- **困局**：不敢辞职（风险承受力低）；想做自媒体但不知内容 = 信息差；不露脸 = 怕被嘲笑（七类）；阶层固化下想找"低门槛出路"。
- **代表问题**：#100 普通人能做什么副业；#105 想做抖音又不想露脸。
- **口播讲法**："你不是没本事，是你不敢拿仅有的本钱赌一次。但副业这东西，小到不可能失败的第一步，才是给你试错的。"
- **落句金句**：「不敢转行不是你怂，是你输不起。那就先赢一次小的。」

## 给你的两条使用纪律

1. **选题时先问**：这条痛点背后是"带宽 / 即时满足 / 自我否定 / 信息差 / 环境锁定"里的哪一个？照那个讲，不要讲"你应该自律"。
2. **每条口播只打一个困局**，别贪。一次讲透"你不是懒，是稀缺心态占用了带宽"，比讲十个道理都管用。
