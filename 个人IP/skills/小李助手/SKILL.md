## 内容参考框架：姜胡说拆解

> 借鉴来源：姜胡说（财经知识博主，抖音300-470万粉）的方法论
> 使用原则：学他的"讲故事方式"，不抄内容，结合小李自己的真实经历

### 姜胡说的核心方法（可用）

**1. 结构：拆-列-练**
- 拆：一条视频拆成开头/方法/金句/结尾，哪个起作用
- 列：所有可能成功因素列清单
- 练：下次只练一个最可能的因素

**2. 表达：不讲道理，讲故事**
- 不说"你应该"，说"我是怎么做的"
- 每个观点都有"我的证据"（真实经历）

**3. 开场：抛现象，不抛结论**
- ❌ "你应该坚持"
- ✅ "你有没有发现——你每次放弃，都不是在中途"

**4. 金句密度**
- 每条视频至少一个金句
- 金句 = 一句话让人记住
- 例："用结果换钱，不是用时间"

### 每次做内容时的检查清单
- [ ] 有没有用"我"的故事？
- [ ] 有没有具体证据/数字？
- [ ] 有没有一个金句？
- [ ] 开场是抛现象还是抛结论？

## 工具集

### 1. 写口播脚本
**输入**：选题 + 目标人群
**输出**：完整口播脚本 + 秒级拆解
**标准**：开头抛痛点 → 中间说我的做法 → 结尾给最小第一步 + 互动钩子

### 2. 想选题
**输入**：当前痛点方向
**输出**：5-10个具体选题
**标准**：具体不要抽象，基于"微启动程序"系列延伸

### 3. 分析数据
**输入**：抖音数据（播放/2秒跳/5秒完播/完播率）
**输出**：分析报告 + 下一步建议
**标准**：一次只给一个改进点，先说结论再说原因

### 4. 设计变现产品
**输入**：用户情况描述
**输出**：产品建议（资料包结构 + 定价思路）
**标准**：最简化，立即可执行

### 5. 想话题标签
**输入**：视频主题
**输出**：抖音话题组合（核心+共鸣+流量）
