## 一、一天时间轴

```
06:00 ──────────────────────────────────────────────── 你醒着就行
 │
09:00 ├─ 🤖 [自动] 抖音数据日报 + 选题推荐 + 执行指标进度
 │     → 你收到：昨日数据卡片 + 3个选题 + 完成率/断裂率提醒
 │     → 你做：看报告，决定今天拍哪条（回我一个字母 A/B/C）
 │
11:30-12:30 ├─ 📱 [你做] 拍摄当天口播（用 AI 给的脚本）
 │           → 结尾必须带互动钩子（扣1领清单）
 │           → 发布到抖音
 │
14:00 ├─ 📱 [你做] 同步发小红书（21:30 会有提醒）
 │
17:00 ├─ 💡 [自动] 随手记提醒（启动拐杖，想关就关）
 │
20:00 ├─ 🔔 [自动] 三件事提醒（口播/复盘/明日改什么）
 │
21:00 ├─ 🤖 [自动] 抓抖音数据 + 写当日数据文件 + 更新执行 frontmatter
 │
21:10 ├─ 🤖 [自动] 飞书日报写入（最强/最弱作品 + 改进点 + 明日计划）
 │
21:30 ├─ 🔔 [自动] 小红书同步提醒
 │
22:00 ├─ 🔔 [自动] 填今日 7 指标 + 口播数据（开头/结尾/发布时间）
 │     → 你做：把今天的数据发我，我存进记录表
 │
23:00 ├─ 🤖 [自动] 知识库备份到 Gitee（commit + push）
 │
每周一10:00 ├─ 🤖 [自动] 对标账号拆解（姜胡说等最新3条）
每周一20:00 ├─ 🤖 [自动] 微信引流检查（看评论区有没有人问）
```

## 四、每日 7 指标（22:00 填）

| # | 指标 | 怎么算 |
|---|------|--------|
| 1 | 完成率 | 做了几个 ÷ 计划几个 |
| 2 | 总用时分钟 | 拍+剪+发+复盘 合计 |
| 3 | 核心目标占比 | 核心任务时间 ÷ 总时间 |
| 4 | 动静卡断裂率 | 超2天没动的任务数 ÷ 总任务数 |
| 5 | 市场验证 | 有留言/私信/付款=有，其他=无 |
| 6 | 优化建议落实率 | 昨天改进今天做了几个 ÷ 建议总数 |
| 7 | 内容合格率 | 开头/中段/结尾/标签/时长/发布时间，符合几项×15分 |

**文件**：`个人IP\口播数据记录表.md`（AI 自动更新 frontmatter）

## 五、口播内容公式（每条都过一遍）

| 段落 | 标准 |
|------|------|
| 开头2秒 | 反差 / 数字 / 痛点 三选一 |
| 中段25秒 | 只讲1个点 + 真实案例（不用抽象步骤） |
| 结尾 | 一句话可带走 + 互动钩子 |
| 标签 | 1核心 + 2-3流量 + 2-3共鸣 = 5-8个 |
| 时长 | 20-40秒 |
| 发布 | 早11:30-12:30 或 晚18:00-19:00 |

**金句密度**：每段至少1句能记住的话

## 九、文案协作闭环（新约定 · 2026-08-20）

```
AI 生成文案
  ↓
你归纳（按你的理解，整理成要点 / 你的版本）
  ↓
AI 找漏洞（你归纳里：漏了什么、错了什么、逻辑哪断了）
  ↓
AI 给解决方案（每条漏洞都给可执行的改法）
  ↓
你拍摄
```

**原则：**
- 你不用写得「对」，先归纳你的理解
- 我专门挑刺，不夸、不绕
- 每个漏洞都配一个「怎么改」
