# 研究：普通人想看什么、什么能调动情绪
> 时间：2026-08-21 | 用途：指导口播"中段"改造（开头已达标，中段掉人）
> 数据来源：4轮 web 搜索（普通人情绪共鸣 / 底层心理需求 / 前3秒钩子 / 焦虑内耗心理学），共40条结果
> 红线：情绪做钩子、价值做内核。**不是操纵情绪，是理解目标受众的真实挣扎，以便真正帮到人。**

---

## 一、普通人刷短视频的底层动机（先想"满足他什么"，再想"讲什么"）

四个字概括用户打开 App 的动机：**快乐、谈资、解决、共鸣**。

| 动机 | 用户行为 | 内容该做的事 |
|---|---|---|
| 快乐 | 点赞（低认知门槛、高情绪回报） | 给爽感、解压、反差 |
| 谈资 | 转发（信息差 + 可转述） | 给"别人不知道的事" |
| 解决 | 收藏（用户是来"搜"的，明确求助预期） | 给可立刻用的工具/步骤 |
| 共鸣 | 评论（替他说出憋了很久的话） | 说出他心里有、嘴上没说的话 |

**对你的启示**：你的账号天然吃"共鸣 + 解决"两条——你的观众是"想改变但卡住的人"，他们不缺道理，缺的是"有人把我那种说不清的憋屈说出来了" + "下一步具体怎么迈"。

## 二、流量的本质 = 情绪，不是干货

- 六大情绪模板：焦虑、共鸣、好奇、愤怒、爽感、治愈。
- 用户刷视频是为了**消遣、解压、找共鸣、找情绪寄托**，没人为"听道理"停留。
- **爆款万能结构**：痛点切入（3秒抓住）→ 人性共鸣（让人看完）→ 价值输出（让人收藏）→ 情绪收尾（让人转发/传播）。
- **核心公式：情绪做钩子，价值做内核。** 纯煽情 = 无效流量、透支口碑。

**对你的启示**：你之前中段掉人，根因就是"在讲方法（价值）但没接情绪"。观众脑子里的反应是"道理我懂，但关我啥事"。每个抽象概念后面必须跟一个**他经历过的画面**。

## 三、普通人最爱看的内容类型（挑能用的）

1. **反差 / 逆袭故事**：底层起点 → 挑战 → 普通人的努力 → 成就。纯卖惨没人看，纯炫富离太远只有难受，要"离观众近的逆袭"。
2. **市井烟火 / 热闹场景**：夜市、集市、街边小摊热汤。原汁原味的生活温度，治愈"看腻精致网红"的打工人。
3. **六大爆款类型**：视觉美感 / 知识干货（收藏率高）/ 正能量励志 / 搞笑解压 / 新奇猎奇 / 才艺展示。
4. **"小事 → 情绪炸弹"**：拍事不如拍情绪；放大细节制造反差；**敢把自己扒开给人看**。例：打工人吃泡面 = 尊严之战；早餐加不加蛋的纠结。

**对你的启示**：你手里的真实素材全是"市井 + 逆袭 + 扒开自己"——减重40斤（200→160）、开店6年看人动作、AI漫剧73万播放0变现的复盘。**这些本身就是最高级的情绪素材，不用编，只怕你讲成方法论。**

## 四、完播率与前3秒钩子（你的开头已过关，这里只备份规律）

- 用户 0.8~3 秒内决定划走；前3秒留存 <40% 算法不给二次推流。
- 四类杏仁核触发器（前3秒只激活**一种**主导情绪，别过载）：威胁感知 / 认知缺口（反常识）/ 预期违背 / 感官突显。
- 八类钩子公式（痛点暴击 / 结果前置 / 反常识颠覆 / 提问 / 警告 / 对比反差 / 利益诱惑 / 故事开头）。
- 你验证过的开头类型：**"你有没有发现……"** 痛点/反常识混合，2秒跳出已做到 21~25%，有效，继续用。

**注意**：研究反复强调——**钩子类型要交替用，别每条都用同一种**。你目前开头句式偏单一，可逐步加入"结果前置"（如"我靠这招，半年没再三分钟热度"）和"反常识"（"真正厉害的人，根本不靠自律"）。

## 五、焦虑内耗人群为什么爱看这类内容（你的核心观众）

- 解压视频（修驴蹄/切肥皂/洗地毯）爆火的心理机制：快节奏高压下"心理内存不够"，把负面情绪投射到网络，用虚拟世界的单调重复消解现实"压力过载"。
- 两类：**破坏型**（情绪喷涌释放）vs **修复型**（获得秩序感、控制感、成就感——"看过即是体验过"）。
- 关键洞察：你的观众不是"懒"，是**长期压力 + 无预期 + 缺控制感**。"你不知道动了有没有用"这句能戳人，正是因为精准命中海洛因的"无反馈焦虑"。

**对你的启示（最重要的一条）**：你讲"反馈模块"为什么中段掉人？因为"反馈模块"是抽象词，观众脑子里没画面。换成画面就是——"你跑步上秤称了一下，数字没变，但你今天动过了，这个'动过了'就是反馈"。**把每个概念翻译成'他身体做过的一个动作'**。

## 六、直接落到你下一条口播的操作清单

**中段改造（当前第一优先级）：**
1. 45秒内只讲**1个点**，不讲2个。
2. 每个抽象词后面必须接**一个具体场景/动作画面**：
   - "反馈模块" → "你跑步上秤称了一下"
   - "三分钟热度" → "你办卡那天觉得自己脱胎换骨，第二周再也没去"
   - "微启动" → "闹钟一响，我先穿鞋，穿鞋就是开始了"
3. 节奏：开头快、中间慢（给画面留半秒）、结尾快。
4. 用"我以前也……"的真实经历当画面，不用"你应该"。

**结尾（已验证方向）：**
- 用"可带走的一句话"留缝隙，不用营销问句。
- 句式模板：「先[稳住一件事]，其他的[慢慢来]。」

**钩子（交替用，别只靠一种）：**
- 继续用："你有没有发现……"（痛点/反常识）
- 逐步加："结果前置"（我靠X，做到Y）+ "反常识"（真正厉害的人不靠自律）

## 七、对你"变油滑"目标的校准

你说过想变成"油滑利己、不要脸、放下尊严去做事的人"。研究结论和你的数据都指向一个更稳的判断：

- **该练的是"敢"**：敢问价格、敢推产品、敢被拒绝、敢让人觉得你有所图。这跟"有人味""真实"不冲突。
- **"油滑"是死路**：口播靠真实吸引人，变油滑=人设塌。你的核心资产是"一个普通人做成过几件事，陪你迈出第一步"，这个资产一旦油滑就归零。
- 真正的公式：**真实 + 敢要 + 真帮人**。帮人时顺便说"我有个东西能帮你"，不丢人。
